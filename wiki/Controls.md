# Controls

| Action | Keys |
| --- | --- |
| Move | W A S D / arrow keys |
| Look | mouse (mouse up = look up), PgUp / PgDn |
| Fire / alternate fire | left mouse or F / right mouse |
| Use, open doors | E |
| Jump / crouch / run | Space / C or Ctrl / Shift |
| Weapons | 1 – 0 |
| Inventory: previous / next / use | `[` / `]` / Enter |
| Quick save / quick load | F6 / F9 |
| Menu | Esc |
| Fullscreen | F11 or Alt+Enter |
| Toggle render scale (100% / 50%) | F5 |
| Screenshot / stats | F12 / F2 |
| Previous / next level | Ctrl+`[` / Ctrl+`]` |
| Test cheat (all weapons, ammo, keys) | F10 |

## Weapons and alternate fire

Right mouse fires the alternate mode:

| Slot | Weapon | Alternate fire |
| --- | --- | --- |
| 1 | Pitchfork | — |
| 2 | Flare pistol | starburst |
| 3 | Sawed-off shotgun | both barrels |
| 4 | Tommy gun | spread |
| 5 | Napalm launcher | big napalm ball |
| 6 | Dynamite | drop |
| 7 | Spray can | spray-can bomb |
| 8 | Tesla cannon | charged shot |
| 9 | Life leech | burst |
| 0 | Voodoo doll | curse |

Shotgun pellets that hit the same target add up, so a point-blank double blast gibs.
The guns akimbo power-up lets you fire two guns at once.

## Inventory

`[` and `]` select an item, Enter uses it: doctor's bag, diving suit, crystal ball, beast
vision, jumping boots. Timed power-ups (invisibility, invulnerability, akimbo, reflective
shots, feather fall, rage) run out on their own.

## Mouse

Mouse speed is in **Options**; inversion is the `invert_mouse` key in `openblood.ini` (see [Configuration](Configuration)). The mouse
is captured while you play and released when the menu is open.
